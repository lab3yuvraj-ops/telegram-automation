# Course correction status

The owner's September 17 correction supersedes the original eight-beat requirement: new scripts contain six spoken beats mapped to Hook, Rupture, Escalation, Truth, Climax and Twist. Each edited scene remains 7.5 seconds, for a 45-second master. Pruna generates 8-second source clips. This is a compact adaptation, not the full-length course script.

The portrait reference informs illustration style only. New requests require 16:9. Character sheets, selected empty background plates and their angles supply the production references. The compiler includes the selected camera and canonical identity descriptions in still prompts and exports the course scene format in each packet's `document` field.

Live plans have a semantic review before media generation, in addition to asset-link and placeholder checks. A failed plan is retained and stops before paid image generation. Visual checks and script critiques are model judgments, not guarantees of perfect anatomy or identity.

Media generation requires Replicate Pruna and a token. Prompt upsampling is disabled. Prediction inputs and status are journaled before submission; ambiguous submissions stop for reconciliation. Saved prediction IDs are polled on resume. Image references are not silently truncated. Landscape images are normalized to 1024x576; incorrect aspect ratios are rejected.

Tests cover six-beat and landscape constraints, selected-camera prompt compilation, exact dialogue inclusion, placeholder rejection, valid repeated-location shots, semantic review rejection, ambiguous prediction submission, fake-provider orchestration, Telegram isolation/delivery and FFmpeg assembly. These tests do not prove live model output quality or current model access. No new billable generation or deployment was performed during this correction.

Existing generated assets and historical jobs were retained. Old eight-scene plans can fail the new six-scene validation; start a new production for the revised contract rather than rewriting a paid production in place.
